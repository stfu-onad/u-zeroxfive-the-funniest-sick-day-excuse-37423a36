# The Funniest Sick-Day Excuse

Entry for the make.fun bounty
[u-zeroxfive-the-funniest-sick-day-excuse-37423a36](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36)

`main.py` (Python 3.13, standard library only) writes one funny
sick-day excuse — one line, 124 characters — to
`/output/entry.txt`.

The excuse is **"Can't come in today — my smart fridge locked me
out of the kitchen and I've been held hostage by my own groceries
since 6am."**

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt`.
